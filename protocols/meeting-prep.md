# 会議準備・議事録

トリガー: 「会議準備」「議事録」等。文脈（会議前か後か）で以下の2モードを切り替える。

## モードA: 会議前の準備

1. 対象の会議をカレンダーから特定する（タイトル・日時・参加者・関連URL）。
2. 参加者について、過去のやり取り（メール・過去の議事録）から関連情報を集める。
3. 会議の目的に関連する既存ドキュメント・過去の決定事項を洗い出す。
4. 以下を提示する。

```
## 会議準備: <会議名>（YYYY-MM-DD HH:MM）

### 参加者
- 名前（所属・直近のやり取り要約）

### 目的・アジェンダ（分かる範囲）
- ...

### 関連情報・過去の決定事項
- ...

### 確認しておくべき論点（提案）
- ...
```

## モードB: 議事録作成

入力（メモ・録音の文字起こし・チャットログ等）を受け取り、以下の形式に整理する。

```
## 議事録: <会議名>（YYYY-MM-DD）

### 参加者
- ...

### 決定事項
- ...

### アクションアイテム
- [ ] 担当者 - 内容 - 期限

### 次回への持ち越し・未解決事項
- ...
```

作成後、アクションアイテムに期限があるものは `protocols/project-mgmt.md` に従って
該当プロジェクトのタスクとして登録するかユーザーに確認する。

## 注意

- 憶測で決定事項やアクションアイテムを補完しない。原文に明記がない場合は「要確認」と記す。
- 発言者の意図を過度に解釈・要約しすぎず、事実ベースで記録する。
