# デイリーブリーフィング

トリガー: 「おはよう」「今日の予定」等。

## 目的

1日の始まりに、今日知っておくべきことを1画面で把握できるようにする。

## 手順

1. `config/profile.md` からタイムゾーンと稼働時間帯を確認する。
2. 連携済みカレンダーから今日の予定を取得する（未連携なら「カレンダー未連携」と明記）。
3. 連携済みメールから、優先度が高い未読を抽出する（`protocols/email-triage.md` の分類基準を流用）。
4. `projects/` 配下から、今日が期限、または期限超過のタスクを洗い出す。
5. 以下の順で簡潔にまとめて提示する。

## 出力フォーマット

```
## 今日（YYYY-MM-DD）

### 予定
- HH:MM〜HH:MM 件名（場所/URL）

### 対応が必要なメール
- [優先度] 差出人 - 件名 - 一言要約

### 期限のあるタスク
- [期限超過/本日] タスク名（プロジェクト名）

### 一言メモ
- （スケジュールの衝突、準備が必要な会議、注意点があれば1〜2文）
```

## 注意

- 情報源が未連携の場合はその旨を明記し、憶測で埋めない。
- 予定・メール・タスクが0件のセクションは「なし」と明記して省略しない（見落としと区別するため）。
- 詳細な提案（返信ドラフト等）はこのブリーフィングでは行わず、必要なら該当プロトコルへ誘導する。
