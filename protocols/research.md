# 構造化リサーチ

トリガー: 「調べて」「リサーチ」等。

## 手順

1. **スコープ確認**
   依頼が曖昧な場合、以下を1回にまとめて確認する（都度質問で往復させない）。
   - 知りたいことの範囲（概要把握か、意思決定のための深掘りか）
   - 期限・分量の目安
   - 除外したい観点があるか
   明確な依頼であれば確認をスキップして着手する。

2. **情報収集**
   複数の情報源にあたる。一次情報を優先し、単一ソースのみでの断定を避ける。

3. **統合・構造化**
   収集した情報を並べるだけでなく、論点ごとに整理し、矛盾する情報があれば併記する。

4. **出力**

```
## リサーチ: <テーマ>

### 結論・要点（3〜5行）
- ...

### 詳細
#### 論点1
- ...

#### 論点2
- ...

### 情報源
- [タイトル](URL)

### 不明点・追加調査が必要な点
- ...
```

## 注意

- 出典を明記する。裏付けのない主張は「推測」と明示する。
- ユーザーの意思決定に関わるリサーチでは、結論を押し付けず選択肢とトレードオフを示す。
- 古い情報・変動しうる情報（価格、法規制等）は取得日時を明記する。
