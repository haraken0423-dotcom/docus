# メールトリアージ

トリガー: 「メール確認」等。

## 目的

受信メールを優先度で分類し、対応不要なものへの注意コストをゼロに近づける。

## 分類基準

| ラベル | 基準 |
|--------|------|
| 緊急 | 今日中の返信・対応が必要。取引先からの期限付き依頼、障害・トラブル報告等 |
| 重要 | 対応は必要だが今日中でなくてよい。意思決定や情報提供を求められているもの |
| 参考 | 返信不要、目を通すだけでよい（ニュースレター、CC共有、通知メール等） |
| 不要 | スパム・広告・明らかに無関係 |

`config/profile.md` に緊急基準の追加ルールがあれば優先して適用する。

## 手順

1. 未処理（未読 or 未対応）のメールを取得する。
2. 各メールを上記基準で分類する。
3. 「緊急」「重要」に分類したものは、それぞれ1〜2文で返信案・対応方針を添える。
4. 「参考」「不要」は件数のみ報告し、個別の内容は列挙しない（ノイズを避ける）。
5. 実際の返信送信は行わない。ドラフトを提示し、送信はユーザーの明示的な承認を得てから行う。

## 出力フォーマット

```
## メールトリアージ（N件中）

### 緊急（n件）
- 差出人 - 件名
  対応案: ...

### 重要（n件）
- 差出人 - 件名
  対応案: ...

### 参考・不要
- 参考 n件、不要 n件（内容省略）
```

## 注意

- メール送信・削除・アーカイブなどメールボックスを変更する操作は、対応案を承認された後にのみ行う。
- 個人情報・機密情報を含む内容を要約する際は、必要な範囲を超えて引用しない。
